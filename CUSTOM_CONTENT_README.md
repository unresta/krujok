# Система управления эмодзи и текстами

## Описание

Система позволяет администратору редактировать премиум-эмодзи и тексты бота через админ-панель без изменения кода.

## Структура

### Таблицы БД

- `custom_emoji` - кастомные премиум-эмодзи
  - `key` - уникальный ключ (например, UPLOAD, LIKE)
  - `emoji_id` - ID премиум-эмодзи Telegram
  - `fallback` - обычный эмодзи для fallback
  - `description` - описание для админки

- `custom_texts` - кастомные тексты
  - `key` - уникальный ключ (например, WELCOME)
  - `text` - текст сообщения
  - `description` - описание для админки

### Модули

- `emoji_manager.py` - управление эмодзи (загрузка из БД, fallback на дефолты)
- `text_manager.py` - управление текстами (загрузка из БД, fallback на дефолты)

### Админка

В админ-панели `/admin` есть две кнопки:
- **Эмодзи** - просмотр и редактирование премиум-эмодзи
- **Тексты** - просмотр и редактирование текстов

## Использование

### Изменение эмодзи

1. Открой `/admin`
2. Нажми "Эмодзи"
3. Нажми "Изменить эмодзи"
4. Отправь сообщение в формате:
   ```
   KEY emoji_id fallback описание
   ```
   Пример:
   ```
   UPLOAD 6028115612163641653 ⬆️ Кнопка загрузки
   ```
5. Перезапусти бота

### Изменение текста

1. Открой `/admin`
2. Нажми "Тексты"
3. Нажми "Изменить текст"
4. Отправь сообщение в формате:
   ```
   KEY|||текст|||описание
   ```
   Пример:
   ```
   WELCOME|||Привет! 👋\n\nЭто бот для обмена кружочками.|||Приветствие
   ```
5. Перезапусти бота

### Сброс к дефолтным значениям

В меню эмодзи или текстов есть кнопка "Сбросить всё", которая удаляет все кастомизации.

## Добавление новых ключей

### Новый эмодзи

1. Добавь в `emoji_manager.py` в `DEFAULT_EMOJI`:
   ```python
   "NEW_KEY": {"emoji_id": "123...", "fallback": "🎉", "description": "Описание"},
   ```

2. Используй в коде через emoji_manager:
   ```python
   import emoji_manager
   emoji_id = emoji_manager.get_emoji_id("NEW_KEY")
   fallback = emoji_manager.get_fallback("NEW_KEY")
   ```

### Новый текст

1. Добавь в `text_manager.py` в `DEFAULT_TEXTS`:
   ```python
   "NEW_TEXT": {
       "text": "Текст по умолчанию",
       "description": "Описание"
   },
   ```

2. Используй в коде через text_manager:
   ```python
   import text_manager
   text = text_manager.get("NEW_TEXT")
   ```

## Миграция существующих значений

Все существующие эмодзи из `emoji.py` уже имеют дефолтные значения в `emoji_manager.py`.
При первом запуске система будет использовать эти дефолты, пока не будут добавлены кастомные через админку.

## Важно

⚠️ После изменения эмодзи или текстов через админку **необходимо перезапустить бота**, 
чтобы изменения вступили в силу.
