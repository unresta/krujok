# Кружочки — анонимный обмен video note

Бот на aiogram 3: смотришь чужие кружочки за монетки, зарабатываешь монетки своими
(после модерации) или покупаешь за Telegram Stars.

## Экономика

| Действие | Монетки |
|---|---|
| Посмотреть кружок | −2 |
| Загрузить женский (одобрен) | +5 |
| Загрузить мужской (одобрен) | +3 |
| Telegram Stars | 1 ⭐ = 3 🪙, минимум 20 ⭐ |

Минимальная длина загружаемого кружка — 8 секунд. Всё меняется в `config.py`.

## Как работает

1. `/start` — панель: баланс, выбранный тип (♀ / ♂ / 🎲 любые), кнопки.
2. «Смотреть» — списывается 2 🪙, приходит случайный неповторяющийся кружок
   выбранного типа. Отправка идёт с `protect_content=True`: переслать или сохранить
   его нельзя. Свои кружочки пользователю не показываются.
3. «Заработать» — пользователь шлёт кружок (можно просто прислать его в любой момент),
   выбирает тип, кружок улетает в админ-чат с кнопками 🟢 Одобрить / 🔴 Отклонить.
   Монетки начисляются только после одобрения.
4. «Купить 🪙» — инвойс в Stars (`currency="XTR"`), пресеты 20/50/100/250 или своя сумма.

UI: одно сообщение-панель, которое редактируется на месте. После просмотра панель
удаляется и пересоздаётся под кружком, чтобы кнопки всегда были внизу.

Про «цвета» кнопок: Bot API не даёт красить inline-кнопки (цвет есть только у главной
кнопки Mini App), поэтому палитра держится на эмодзи и она единая по всему боту —
🟢 действие/подтверждение, 🔵 деньги и навигация, 🔴 отмена/отказ.

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_CHAT_ID, ADMIN_IDS
python bot.py
```

`ADMIN_CHAT_ID` — чат модерации (бот должен быть там админом, id вида `-100…`).
`ADMIN_IDS` — личные id через запятую, для команд ниже.

## Админ-команды

- `/stats` — пользователи, кружки, просмотры, звёзды
- `/give <user_id> <coins>` — начислить (можно отрицательное)
- `/ban <user_id>` · `/unban <user_id>`
- `/refund <charge_id>` — вернуть Stars покупателю и списать выданные монетки

`charge_id` лежит в таблице `payments`. Возврат звёзд обязателен по правилам
Telegram для цифровых товаров, поэтому команда есть по умолчанию.

## Хранилище

SQLite (`bot.db`, WAL). Таблицы: `users`, `circles`, `views`, `payments`.
Списание монеток атомарное (`UPDATE … WHERE coins >= ?`), повторный `charge_id`
не начисляется дважды, дубли кружков режутся по `file_unique_id`.

FSM — `MemoryStorage`: при перезапуске незавершённые шаги (выбор типа, ввод суммы)
сбрасываются. Для нескольких воркеров нужен Redis-storage.
